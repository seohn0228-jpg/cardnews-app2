# cardnews-app2
## 네이버 쇼핑커넥트 블로그 원고 작성 (Claude Code 스킬)

이 저장소를 연 Claude Code 채팅에 쇼핑커넥트 상품 링크를 붙여넣으면 아래 작업을 합니다.

1. 상품 사진과 장점 정리
2. 네이버 자동완성 기반 키워드 조사
3. 사람이 쓴 것 같은 원고 작성 (제목 후보 3개, 본문, 사진 위치, 태그)
4. SEO 점검

API 키는 필요 없습니다. 발행 버튼은 직접 누릅니다.
예: `이 링크로 블로그 글 써줘 https://naver.me/xxxx (써본 느낌: 배송 빠르고 생각보다 가벼움)`

작성 규칙과 스크립트는 `.claude/skills/naver-shopping-post/`에 있습니다.
